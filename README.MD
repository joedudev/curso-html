## 💡 What I Learned

Throughout this course, I mastered the core structure of web pages using clean, hierarchical, and functional HTML5. Key takeaways include:

* 🏗️ **Semantic HTML5:** Using tags like `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>` to create meaningful page structures that enhance both SEO and accessibility.
* 🌐 **Web Architecture & Rendering:** Understanding how browsers request, parse, and render HTML pages from URLs.
* 📝 **Forms & Native Validation:** Building robust forms with diverse input types (`checkbox`, `select`, `email`, etc.) and enforcing native validation without relying on JavaScript.
* 🖼️ **Responsive & Rich Media:** Implementing responsive images using `srcset` and `<picture>`, as well as native `<video>` and `<audio>` players.
* ♿ **Web Accessibility (a11y) & ARIA:** Applying ARIA attributes and accessible design practices so screen readers can navigate content effortlessly.
* 📊 **Structured Data Tables:** Building semantic data tables using `<thead>`, `<tbody>`, and `<tfoot>`.
